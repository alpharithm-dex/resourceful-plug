# Resourceful Plug

**When the web says no, your agent finds the valid next step—in your language.**

Resourceful Plug is a Kiswahili-first WebMCP recovery layer demonstrated through a fictional permit portal. When a standard action is blocked, the website returns a structured Resolution Contract containing legitimate alternatives. After the person approves one, the site exposes the precise temporary capability the agent needs to continue.

## Why WebMCP

Translation can explain a rejection. WebMCP lets the website expose an executable, typed recovery path without forcing an agent to scrape the interface or invent a workaround. Top-level imperative tools use the same deterministic domain engine as the human interface.

## Boundaries

- Fictional demonstration software; not a government service or legal advice.
- Synthetic identities and records only.
- The website owns requirements, recovery paths and authorization.
- The complete portal remains usable without WebMCP or voice input.
