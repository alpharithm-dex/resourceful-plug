# Resourceful Plug repository rules
- Never commit credentials, real personal data, or real identity documents.
- Do not claim browser compatibility, language review, or evaluation success without evidence.
- The deterministic domain engine owns requirements and valid recovery paths.
- The model may interpret intent but cannot authorize, confirm, or bypass state transitions.
- Keep the human interface functional when WebMCP is absent.
- Register imperative WebMCP tools in the top-level page, not an iframe.
- Run lint, tests and a production build before claiming completion.
